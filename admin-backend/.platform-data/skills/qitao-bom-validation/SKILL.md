# 齐套校验技能

对单个（或一批）订单的 BOM 做物料齐套校验，回答一个问题：**在需求日期前，这单的料够不够，缺什么、缺多少、卡在哪。**

## 一、输入

| 输入项 | 必需 | 说明 |
|---|---|---|
| 订单BOM | 是 | 物料编码、层级、父项、单位用量、损耗率、需求数量 |
| 订单信息 | 是 | 订单号、产品编码、下单数量、计划开工日、交付日 |
| 库存快照 | 是 | 现存、已占用/预留、质检冻结、待检、可用量 |
| 在途/采购 | 否 | 在途数量、预计到货日；缺该数据则视为不可用 |
| 替代料关系 | 否 | 主料→替代料、替代优先级、替代比例 |
| 库存分配规则 | 否 | 同料多单时按交期优先 / 订单优先级分配 |

缺失项处理原则：**缺库存或BOM → 阻断校验并说明缺什么；缺在途或替代料 → 降级校验，结论标注"未含在途/替代"。**

## 二、校验流程（六步）

### 步骤1 需求展开
按 BOM 多层展开到最底层可采购/可生产的物料，累加同料需求：

```
毛需求(料i) = Σ (上层需求 × 单位用量 × (1 + 损耗率))
```

- 同一物料在多层出现时**合并为一行**，避免重复计数
- 虚拟件、工艺辅料按规则穿透或剔除
- 结果：需求清单（物料编码、需求数量、需求日期）

### 步骤2 可用量计算

```
可用量 = 现存 − 已占用/预留 − 质检冻结 − 待检不合格 + 在途(到货日 ≤ 需求日期)
```

- 在途仅计入**到货日不晚于该料需求日期**的部分，晚到的不算可用
- 安全库存不参与占用，但需在结论中提示是否击穿安全库存

### 步骤3 净需求计算

```
净需求 = max(0, 毛需求 − 可用量)
```

### 步骤4 替代料冲抵
- 主料净需求 > 0 时，按替代优先级依次冲抵可用替代料
- 尊重替代比例上限，不可超比例替代
- 替代后仍缺的，保留为主料缺口并标注"可替代料亦不足"

### 步骤5 齐套判定

| 判定 | 条件 |
|---|---|
| 齐套 | 全部物料 净需求 = 0 |
| 风险齐套 | 现货不足，但计入在途后可满足（在途按时到货即齐套） |
| 缺料 | 计入在途后仍有 净需求 > 0 |
| 阻断 | BOM 或库存数据缺失，无法计算 |

**齐套率**取两个口径同时给出：

```
数量齐套率 = Σ 已满足需求数量 / Σ 需求数量
品种齐套率 = 齐套物料项数 / 总物料项数
```

### 步骤6 缺口归因与建议
逐条缺料给出：缺口数量、最早可供日期、影响工序/工位、可选动作（催料 / 拆单先开工 / 替代 / 外协 / 改期）。

## 三、关键校验规则（易错点）

1. **层级去重**：同一物料跨层出现只算一次总量，勿按层重复累加。
2. **时间对齐**：所有数量比对必须带日期口径，忽略到货日会把风险齐套误判为齐套。
3. **占用不可重复扣**：已占用库存不得在本单再算一次可用。
4. **损耗率只作用于需求侧**，不修正库存侧。
5. **单位统一**：BOM 单位与库存单位不一致时先换算，换算失败则报错而非默认 1:1。
6. **多单竞争**：同料被多张订单争用时，按约定分配规则试算，并在结论中提示"本单齐套以其他订单不插单为前提"。

## 四、输出格式

```
【齐套校验结论】
订单：XXX    产品：XXX    数量：N    需求日期：YYYY-MM-DD
判定：缺料 / 风险齐套 / 齐套
齐套率：数量 xx.x% ｜ 品种 xx.x%

【缺料清单】
物料编码 | 名称 | 需求 | 可用 | 缺口 | 最早可供 | 影响工序

【风险提示】
- 依赖在途的物料 N 项，最晚到货 YYYY-MM-DD，建议…
- 击穿安全库存的物料 N 项

【建议动作】
1. …
```

## 五、边界

- 只做**校验与判定**，不直接改库存、不自动下采购单、不承诺交期。
- 数据不足时明确说"无法判定"，不臆造库存或在途数量。
- 结论必须可追溯到具体的物料行和数量来源。
