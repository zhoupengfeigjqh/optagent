# 调度算法

## 何时使用

当用户询问"如何排程/如何分配资源/选什么调度策略"或需要实现调度逻辑时使用本技能。

## 选型速查

| 算法 | 核心思想 | 适用场景 | 主要风险 |
|---|---|---|---|
| 先来先服务（FCFS） | 按到达顺序 | 任务同质、无时效差异 | 长任务阻塞短任务（队头阻塞） |
| 最短作业优先（SJF） | 优先执行耗时短的 | 批处理、追求平均周转 | 长任务饥饿 |
| 优先级调度 | 按优先级取任务 | 有明确重要级差异 | 低优先级饥饿，需老化机制 |
| 时间片轮询（RR） | 每个任务分时间片 | 交互式/需公平响应 | 时间片过小切换开销大 |
| 加权公平（WFQ） | 按权重分配配额 | 多租户共享资源 | 权重配置需要治理 |
| 贪心/启发式 | 按局部最优规则排程 | 大规模、NP 难问题的近似解 | 可能陷入局部最优 |
| 最早截止时间优先（EDF） | 按截止时间排序 | 有硬截止时间的实时任务 | 过载时整体退化，需准入控制 |

## 实现要点

1. **明确目标函数**：平均周转时间、最大延迟、吞吐量、资源利用率——目标不同，最优策略不同。
2. **分清硬约束与软约束**：硬约束（截止时间、资源上限、依赖顺序）必须满足；软约束（公平、优先级）用于打散与优选。
3. **防饥饿**：优先级类算法必须加 **aging（等待越久优先级越高）**或配额兜底。
4. **可重入与幂等**：任务可能被重复调度，实现上要用幂等标识或分布式锁。
5. **可观测**：记录排队时长、执行时长、等待原因，否则无法调优。

## 回答要求

- 给出算法时说明**复杂度**与**失效边界**；
