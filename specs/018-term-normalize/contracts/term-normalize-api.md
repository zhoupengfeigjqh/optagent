# 契约：术语替换预检与发消息增量字段（018）

- **归属特性**：`specs/018-term-normalize`
- **变更类型**：新增端点（1 个）+ 发消息端点**增量可选字段**（1 个）；无破坏性变更

---

## 1. `POST /api/term-normalize`

发送前的**一次性预检**。归属数字人取服务端"当前选中数字人"（与其余端点同源），客户端不能指定。

### 请求

```json
{ "content": "帮我看下供应商信息的物料库存" }
```

| 字段 | 必填 | 约束 | 说明 |
|---|---|---|---|
| `content` | 是 | 非空字符串 | 提交层正文（已剥离 `@` 引用标记） |

**严格体**：未知字段 → `400 VALIDATION_FAILED`（默认 ajv 会静默丢弃，故本端点显式拒绝）。

### 响应 200

```json
{
  "applied": true,
  "original": "帮我看下供应商信息的物料库存",
  "normalized": "帮我看下供应商或供应商编号的原材料库存",
  "matches": [
    { "term": "供应商信息", "value": "供应商或供应商编号", "start": 4, "end": 9 },
    { "term": "物料", "value": "原材料", "start": 10, "end": 12 }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `applied` | 是否真的发生替换（`value === term` 不算） |
| `original` | 原样回显请求的 `content` |
| `normalized` | 替换后文本；`applied:false` 时与 `original` 相等 |
| `matches[]` | 命中明细；`start`/`end` 是原话的 **UTF-16 下标**（开区间），供前端高亮 |

### 行为口径

- 意图聚焦开关关闭 → **不读任何字典**，直接返回 `applied:false`。
- 无字典文件 → `applied:false`（不是错误）。
- 部分字典损坏 → 跳过该本体 + `warn`（`event: term_normalize.degraded`），其余照常。
- 开关读取失败 → `warn`（`event: term_normalize.gate`），按关闭处理（fail-closed）。

### 错误

| 状态 | code | 触发 |
|---|---|---|
| 400 | `VALIDATION_FAILED` | 缺 `content` / 空串 / 含未知字段 |
| 409 | `AGENT_NOT_SELECTED` | 未选中数字人 |
| 409 | `AGENT_NOT_AVAILABLE` | 选中但配置不可用 |

## 2. `POST /api/threads/:id/messages` —— `original_content`（**已停用，仅兼容保留**）

2026-11-07 二次拍板：**展示与提交同源**。用户点了"使用替换后"（哪怕手改过），聊天区、
历史与模型输入必须都是同一段文本，否则用户会以为替换没生效。客户端因此**不再发送**
`original_content`；服务端仍接受该字段（兼容旧客户端），收到时按旧语义落盘。

```json
{
  "content": "帮我看下供应商或供应商编号的原材料库存"
}
```

| 字段 | 必填 | 约束 | 说明 |
|---|---|---|---|
| `content` | 是 | 非空字符串 | **唯一正文**：模型、气泡、历史三处同源 |
| `original_content` | 否 | 非空字符串 | **已停用**；新客户端不产生，服务端保留解析以兼容旧版本 |

语义：
- 新客户端：`content` = 用户最终确认的那一版（替换文或手改文本），三处一致；
- 旧客户端若仍发送：服务端沿用原处理（`content` 给模型与意图聚焦，`original_content` 落盘）
  ——能力保留、不回退，但本项目前端已不产生；
- 该字段**不参与** SSE 事件序列。

---

## 3. 兼容性

- 新端点独立，旧客户端不调用即完全无感。
- `original_content` 是增量可选字段且**已停用**：服务端保留接受能力，新客户端不再产生，无迁移成本。
- 术语字典（`term_mapping.json`）仍由 017 在部署期生成，本特性只读。
