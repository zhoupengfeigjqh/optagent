# 快速验证指南：预览面板的「放大 / 缩小」

**Feature**: `011-preview-maximize` | **Date**: 2026-10-16 | **Spec**: [spec.md](./spec.md) | **契约**: [contracts/ui-contract.md](./contracts/ui-contract.md)

> 本文是**跑起来验一遍**的指南：自动化门禁在本地（宿主机）执行，容器**不参与测试**（宪章原则三）。
> 不含实现代码；判据与状态语义见 [data-model.md](./data-model.md)。

## 1. 前置

| 项 | 要求 |
|---|---|
| 工具链 | Node ≥ 20；`cd frontend` 后 `npm ci`（用锁文件，宪章原则六） |
| 后端（只需手工验收时） | `agent-backend` 跑在 `3000`，Vite dev（`5173`）经代理把 `/api` 转发过去 |
| 浏览器 | 支持 `inert` 的现代浏览器（Chrome 102+ / Safari 15.5+ / Firefox 112+） |

**没有后端也能验**：放大入口的**同源 iframe** 路径只需要一个同源、可内联的地址——前端 dev server 自身是一条 SPA 路由即可，
例如把它当作 `viewUrl` 的值：`http://localhost:5173/taskresult?taskNo=demo`（响应是 `text/html`、无 `attachment` ⇒ 预检为"可内联"）。
本地 PDF / 图片两条路径需要文件空间里真的有这两类文件（可从聊天区 `@` 引用后上传）。

## 3. 手工验收（含视觉与层级，自动化测不到的部分）

启动：`cd frontend && npm run dev`，浏览器打开 `http://localhost:5173`。

### 3.1 主线：平铺与恢复（`FR-003` / `FR-004` / `FR-006`）

| # | 操作 | 期望（用户可感知） |
|---|---|---|
| 1 | 在聊天区点一个同源 `viewUrl` 入口 | 右侧面板出现该页面（iframe），面板头部**标题 = 入口名** |
| 2 | 看头部动作区 | 「收起」（X）**左侧**有「放大页面」按钮；右侧没有别的按钮 |
| 3 | 点「放大页面」 | 预览**铺满整个视口**（左栏与中栏被完全盖住，不露缝隙）；头部仍可见 |
| 4 | 观察同一按钮 | 已变为「缩小页面」（悬停提示与读屏名称同步变化） |
| 5 | 点「缩小页面」 | 回到放大前的**一模一样**：宽度、内容、滚动位置都在；**无闪白、无加载中**（内容未重新拉取） |
| 6 | 先拖分隔条把面板拉窄，再放大 → 缩回 | 宽度回到**拉窄后**的值（不是默认 1/3） |
| 7 | 放大状态下按 F5 刷新 | 回到**非**放大态（地址栏也没有多出任何参数） |

### 3.2 键盘与退出（`FR-020` / `FR-021` / `FR-023`）

| # | 操作 | 期望 |
|---|---|---|
| 8 | Tab 到「放大页面」，按 Enter / 空格 | 进入放大态；焦点环可见 |
| 9 | 放大态按 Esc | 退出放大态 |
| 10 | **让 agent 输出一段长回答，趁输出中放大，再按 Esc** | 只退出放大；**回答继续输出，不被中断** |
| 11 | 同一场景：焦点先点进 iframe 页面内部，再按 Esc | 同样只退出放大（同源 iframe 内的 Esc 已转发） |
| 12 | 非放大态、回答输出中按 Esc | 与改动前一致：**中断本轮** |
| 13 | 放大态下先触发「删除文件」二次确认弹窗，再按 Esc | **先关弹窗**（放大态不受影响） |

### 3.3 不打扰（`FR-030` / `FR-031`）

| # | 操作 | 期望 |
|---|---|---|
| 14 | 输入框打半句话，消息列表上翻一些，再放大 → 缩回 | 草稿与滚动位置**逐字 / 逐像素**保持 |
| 15 | agent 流式输出中放大并停留 | 输出继续；缩回后中栏是最新内容 |
| 16 | 放大期间按 Tab 反复前进 | 焦点**不会**落到被盖住的控件上（左栏 / 中栏 / 分隔条均 `inert`）；焦点只在面板头部与面板内容之间移动 |

### 3.4 范围边界（`FR-010` / `FR-011` / `FR-013` / `SC-008`）

| # | 打开的内容 | 期望 |
|---|---|---|
| 17 | 同源 `viewUrl` 的 iframe 页面 | 有「放大页面」入口 ✅ |
| 18 | 文件空间里的 **PDF** / **图片** | 有入口 ✅；放大 / 缩小与 iframe 表现一致（内容不重新加载） |
| 19 | 纯文本文件（`.txt` / `.csv` / `.json`） | **没有**入口——动作区与改动前完全一致 ❌ |
| 20 | 需下载的入口（预检为 `attachment` 或类型不可内联） | **没有**入口；仍是"打开"引导 ❌ |
| 21 | 预检失败 / 超限 / 不存在（错误态） | **没有**入口；仍是"下载完整文件"引导 ❌ |
| 22 | 面板停在文件空间列表 | **没有**入口 ❌ |
| 23 | 把正在预览的文件删掉 | 退回列表态，且**不是**全屏（放大态一并退出） |

### 3.5 层级与展示（`R7` / `FR-033`）

| # | 操作 | 期望 |
|---|---|---|
| 24 | 放大态下让 toast 出现（例如一次失败的下载） | toast **浮在**放大层之上，可见 |
| 25 | 放大态下拖拽 / 缩放浏览器窗口、改分辨率 | 预览仍铺满视口，不出现露出底层栏的缝隙，不出现横向滚动条 |
| 26 | 系统开启"减少动效" | 放大 / 缩小仍为静态切换（本实现未加过渡动画，属"不适用"） |

## 4. 失败即登记（不得静默放过）

出现下列任一情况，MUST 当次登记并修，不得以"看起来还行"收尾：

- 缩回后面板宽度 / 内容 / 滚动位置与放大前不一致（`FR-004` / `FR-030`）；
- 放大或缩回时预览内容重新加载（闪白、`iframe` 重建）（`FR-006`）；
- 放大态下找不到「缩小」入口，或按 Esc 无法退出（`FR-005` / `FR-021`）；
- 非放大态按 Esc 不再中断本轮回答（`FR-021` 的回归）；
- 范围外的三类内容（文本 / 需下载 / 错误态）上出现任何新按钮（`FR-013` / `SC-008`）。

## 5. 部署侧（仅确认可达，不作为测试结论）

前端为静态产物、由 `gateway`（nginx）托管；本特性**不改动** `docker-compose.yml` / `gateway/nginx.conf` / 任何后端镜像，
故部署冒烟沿用仓库既有步骤（`docker compose up -d --build` 后打点 `/` 与 `/api/*` 的状态码）。
该步骤只确认"部署本身成功"，**MUST NOT** 作为测试结论（宪章原则三 / 八）。
