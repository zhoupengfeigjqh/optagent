# 快速验证指南：Agent 前端交互页面

**Feature**: 001-agent-chat-ui | **日期**: 2026-09-10 | **依据**: [spec.md](spec.md)、[data-model.md](data-model.md)、[contracts/](contracts/)

本文件是**验证与运行指南**，用于证明功能端到端可用；实现细节见 `tasks.md` 与实现阶段产出。

---

## 一、前置条件

| 项 | 要求 |
|---|---|
| Node.js | ≥ 20（与 `agent-backend` 一致） |
| 包管理器 | npm |
| 后端服务 | `agent-backend` 已启动并监听 `http://localhost:3000`（默认端口） |
| 数字人配置 | 后端 `config.yaml` 中至少 1 个可用数字人，且已配置至少 1 个 MCP 服务（用于验证红/绿状态） |
| 模型配置 | 后端 `config.yaml` 中至少 2 个模型（用于验证模型切换与"默认"标识） |
| 浏览器 | Chrome/Edge ≥ 120、Firefox ≥ 120 或 Safari ≥ 17 |

后端启动（在 `agent-backend` 目录）：

```bash
npm install
npm run dev
# 期望：日志出现监听 3000 端口；curl http://localhost:3000/api/monitor/health 返回 {"status":"ok",...}
```

## 二、首次安装与运行

```bash
# 在 frontend 目录
npm install                 # 安装依赖
cp .env.example .env.local  # 可选：覆盖 VITE_API_BASE_URL（默认走 Vite 代理，无需配置）
npm run dev                 # 启动开发服务器，默认 http://localhost:5173
```

期望：浏览器打开 `http://localhost:5173`，看到三栏骨架；`/api/*` 请求经 Vite 代理转发到后端（浏览器网络面板中请求域名为 `localhost:5173`）。

生产构建与本地预览：

```bash
npm run build               # 类型检查 + 生产构建，输出 dist/
npm run preview             # 本地预览 dist/
```

## 四、端到端验证场景

每个场景标注对应的验收标准编号（`spec.md`），按顺序执行即可覆盖全部 P1/P2/P3 能力。

### S1. 初始入口与对话展开（US1 场景 1-3）

1. 清空 `sessionStorage` 后打开页面。
2. **期望**：对话入口垂直居中，聊天区未展开，输入区下方可见加号 / 思考开关 / 模型按钮。
3. 在入口输入"你好"并点击发送。
4. **期望**：聊天区展开，入口下移至底部；出现旋转的"思考中"提示；发送按钮置灰。

### S2. 思考模式折叠与快速模式（US1 场景 7-8、FR-021/022）

1. 将思考开关切到"思考"，发送一条会触发推理的问题。
2. **期望**：回复完成后，思考内容以折叠块呈现且**默认收起**；点击展开可见内容，再次点击收起。
3. 将开关切到"快速"再发送一条。
4. **期望**：不出现思考块。

### S3. 工具调用展示（US1 场景 4、FR-005、SC-011）

1. 发送一条会触发工具调用的请求（如"读取 生产计划 目录下的文件并统计行数"）。
2. **期望**：出现工具名徽标（如 `read_file`）与进行状态；**不出现**任何入参或结果内容。
3. 该工具执行结束后。
4. **期望**：对应徽标消失。
5. 用浏览器 DevTools 检查该气泡 DOM。
6. **期望**：DOM 中不存在工具入参/结果文本。

### S4. 中断本轮（US1 场景 6、FR-007）

1. 发送一条长回复请求。
2. 回复生成中点击"中断本轮"。
3. **期望**：生成停止；该轮不出现复制/点赞/点踩与 token、耗时；后端 `GET /api/threads/{id}` 中该轮无 assistant 落盘消息。

### S5. 消息操作与用量（US2、FR-024~FR-028）

1. 完成一轮对话。
2. **期望**：消息下方出现复制、点赞、点踩，以及 `输入 x · 输出 y tokens` 与耗时（如 `4.2s`）。
3. 点击复制 → 期望内容进入剪贴板并有成功提示。
4. 点击点赞 → 期望点赞选中、点踩未选中；再点点赞 → 期望取消选中。
5. 点击点踩 → 期望点踩选中、点赞未选中。
6. 刷新页面并重新打开该会话 → 期望反馈状态保持。

### S6. 上传入口与失败提示（US3 场景 2-4、FR-009~FR-011、SC-021）

1. 点击输入区最左侧加号。
2. **期望**：出现 **9 个**目录入口：生产计划、产线信息、切换时间、求解时间、产线电价、目标优先级、使用规则、共享空间（`shared`）、临时空间（`tmp`）。
3. 在"生产计划"中选择 2 个 `.csv` 文件上传。
4. **期望**：两个文件各自展示上传状态并先后变为成功；文件出现在 `@` 引用面板与工作空间面板的同一目录下。
5. 选择一个 60MB 的文件上传。
6. **期望**：**不发起请求**，直接提示"文件超过 50MB"并提供重试。
7. 选择一个 `.docx` 文件上传。
8. **期望**：提示"文件格式不支持"并提供重试。
9. 停掉后端服务后上传一个合法文件。
10. **期望**：提示网络/服务错误原因并提供重试；恢复后端后点击"重试"成功。

### S7. 模型与思考开关（US3 场景 5-7、FR-012/013）

1. 点击模型按钮。
2. **期望**：列出全部模型并标注"默认"；当前项为选中态。
3. 选择一个非默认模型，发送消息。
4. **期望**：请求体 `model` 为该模型（DevTools Network 面板核对）。
5. 手动构造一个不存在的模型（临时改 `sessionStorage` 值后发送）。
6. **期望**：提示"所选模型不可用，请重新选择"，**且输入内容被保留**。

### S8. `@` 引用空间文件（US4、FR-014~FR-019、SC-019）

1. 在输入框中输入 `@`。
2. **期望**：100ms 内出现 **9 个**空间文件夹（与加号入口的 9 个完全一致）。
3. 展开"生产计划"。
4. **期望**：展示该目录文件列表；展开一个空目录 → 展示空态提示。
5. 选择一个文件。
6. **期望**：输入框插入 `@文件名`；面板收起。
7. 连续选择 10 个文件后再选第 11 个。
8. **期望**：阻止添加并提示引用数量上限。
9. 删除输入框中的 `@` 触发符。
10. **期望**：面板收起且对应引用被移除。
11. 发送消息后核对请求体。
12. **期望**：`content` 为正文（不含 `@文件名` 文本），`attachments` 为 `[{dir, filename}, ...]` 结构化数组。
13. 刷新会话历史。
14. **期望**：用户消息仍以 `@文件名` 形式展示引用（由 `attachments` 还原）。

### S9. 数字人与 MCP 状态（US6、FR-032~FR-038）

1. 未选择数字人时打开页面。
2. **期望**：聊天区上方提示需要选择数字人；MCP 列表为空。
3. 点击右上角数字人按钮 → 选择一个数字人。
4. **期望**：聊天区上方展示数字人名称；MCP 服务以红/绿 + 文本（连接失败/连接正常）展示。
5. 在面板的"可切换的数字人"列表中点击**另一个**数字人的名称。
6. **期望**：详情区切换为该数字人的描述/技能/已启用工具/MCP 清单，并标注"预览中 · 未选中，仅查看配置"，切换入口变为"切换到此数字人"；Network 面板确认**未发出** `/exit`、`/select` 请求；点击当前数字人名称回到当前视图。
7. 发送一条消息，在回复生成过程中点击数字人按钮。
8. **期望**：**切换**按钮置灰不可用，并说明"会话进行中"原因；但**预览**仍可用（点击候选名称能看明细，只是"切换到此数字人"同样置灰）。
9. 等本轮结束后切换另一个数字人。
10. **期望**：流程为"退出当前 → 选定新数字人"（Network 面板可核对 `/exit` 先于 `/select`）；提示下一轮生效；详情区自动收敛回"当前"视图（"预览中"标识消失）。
11. 在 MCP 服务不可用时发消息。
12. **期望**：仅展示红色失败状态，**不出现**额外弹窗或阻断。

### S10. 历史会话与新建（US5、FR-039~FR-044）

1. 准备 12 个以上历史会话。
2. **期望**：左栏默认展示 10 条（按更新时间倒序），每项可点击。
3. 打开 DevTools 的 Network 面板，点击"更多"。
4. **期望**：**不产生新的网络请求**（`GET /api/threads` 不支持分页参数，10/100 条由前端切片），
   列表展示最近 100 次会话。
5. 点击某条历史 → 期望聊天区加载该会话消息（时间正序），标题取首条用户消息前 20 字。
6. 点击"新建会话"。
7. **期望**：出现空白会话；若未选数字人 → 提示"请先选择数字人"；
   若数字人不存在或配置异常 → 提示对应原因。
   **会话总数不设上限**：连续新建 4 个以上都应成功（上限只作用于"同时进行中"的会话）。
8. 清空所有会话后查看左栏。
9. **期望**：展示空态且"新建"仍可用。

### S11. 搜索与工作空间（US8、FR-029~FR-031、SC-009）

1. 点击聊天区右上角搜索按钮，输入一个在会话中出现多次的关键词。
2. **期望**：全部匹配以**黄色高亮**显示，并定位到首个匹配。
3. 再次点击搜索（或按 Enter）。
4. **期望**：跳转到下一个匹配；到末尾后循环回首个匹配。
5. 输入一个不存在的关键词。
6. **期望**：展示无结果提示。
7. 点击工作空间文件按钮。
8. **期望**：右侧 1/3 展开面板，按 **9 个**目录分组展示，分组**默认全部收起**。
9. 展开一个有文件的目录；再展开一个空目录。
10. **期望**：前者列出文件（文件名 + 大小 + 下载/删除入口），后者展示空态提示。
11. 点击某个文件名。
12. **期望**：**同一面板内**切换为内容预览（列表让位，两者不并存）；点「返回」回到列表且面板保持展开。
13. 点击非 `shared` 目录中某文件的删除入口，再点击 `shared` 目录中某文件。
14. **期望**：前者弹出二次确认，确认后提示成功且该条从列表消失；后者**不展示**删除入口（共享目录只读）。

### S12. 跳转与右侧预览（US7、FR-002、FR-045~FR-048、SC-008）

1. 让回复中包含一个 `https://` 地址，点击它。
2. **期望**：浏览器新开该外部地址；右侧工作空间面板**不**发生变化。
3. 上传一个 `.txt` 文件，通过 `@` 引用并在回复中点击它（或从工作空间面板点击）。
4. **期望**：右侧约 1/3 宽面板由列表态切为内容态，内联展示文件内容，1s 内开始呈现。
5. 点击一个 `.pdf` 文件。
6. **期望**：面板内以内联方式渲染 PDF。
7. 点击一个 `.xlsx` 文件。
8. **期望**：回退为下载该文件。
9. 点击一个已被删除的文件（可在 `tmp` 中先删除）。
10. **期望**：面板提示"文件不存在或已被清理"。
11. 点击一个超过预览上限（10MB）的文件。
12. **期望**：面板提示"文件过大，请下载查看"并给出下载按钮。

### S13. 流式断连恢复（FR-049/050、SC-020）

1. 发送一条长回复请求。
2. 在生成过程中用 DevTools 将网络切为 Offline（或关闭后端）。
3. **期望**：聊天区提示连接断开，且说明本轮仍在服务端继续执行；提供"重新获取"操作。
4. 恢复网络后点击"重新获取"。
5. **期望**：1 次操作内看到本轮的最终完整结果。

### S14. 无障碍与键盘操作（FR-051、SC-007）

1. 仅用 `Tab` / `Shift+Tab` 遍历页面。
2. **期望**：所有控件可获得焦点，焦点样式可见，顺序合理（左栏 → 中栏头部 → 消息操作 → 输入区 → 右栏）。
3. 用键盘完成：发送消息、切换思考模式、展开思考内容、复制回复、切换会话、搜索跳转、`@` 选择文件。
4. **期望**：全程无需鼠标即可完成。
5. 打开数字人面板 / 工作空间面板，按 `Esc`。
6. **期望**：面板关闭，焦点回到触发按钮。
7. 在系统设置中开启"减少动态效果"。
8. **期望**："思考中"与加载动效降级为静态文本，不影响功能。

## 六、与后端契约的一致性核对清单

验证时如出现不一致，以后端契约为准并同步修订 `contracts/backend-api.md`。

- [ ] 9 个目录在**上传入口**、`@` 面板、**工作空间**三处完全一致（SC-021）。
- [ ] 发消息请求体字段名为 `content` / `thinking` / `model` / `attachments`。
- [ ] `attachments` 元素为 `{ dir, filename }`，非字符串数组。
- [ ] SSE 事件名与 `sse-events.md` 一致：`thinking` / `content` / `tool_call` / `tool_call_end` / `done` / `error`。
- [ ] `done.message_id === null` 时按"中断"处理，不展示操作与用量。
- [ ] 反馈接口重复提交同值 = 取消（提交 `null`）。
- [ ] 历史消息中不含思考内容与工具调用信息（SC-018）。
- [ ] `.xlsx` 预览回退下载；预览超限为 `413`。
- [ ] 开发环境 `/api` 请求经 Vite 代理，浏览器中无跨域请求。
- [ ] `GET /api/threads` 请求**不含** `limit`/`offset`（该接口不支持分页，10/100 条为前端切片）。
- [ ] 上传多选时**逐文件各发一次请求**（后端为单文件接口），响应中的 `filename` 直接采用，不自行拼接。
- [ ] 耗时展示统一为 1 位小数（后端 `duration_seconds` 精度不固定）。
- [ ] 数字人切换在会话进行中时**前端置灰**，且不发请求（后端无兜底校验，见 §7 差异 3）。
