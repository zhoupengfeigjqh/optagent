# 功能规范：Agent 前端交互页面

**功能分支**: `001-agent-chat-ui`

**创建日期**: 2026-09-10

**状态**: 草稿

**输入**: 用户描述："构建一个 Agent 的前端交互页面，类似 workbuddy 风格样式。整体为三栏布局（左历史对话、中聊天区、右侧跳转预览区）；初始入口居中，发起对话后聊天区展开、入口下移；输入区提供文档上传（多入口）、思考/快速切换、LLM 模型选择；等待回复时展示思考中动画；思考模式下思考内容默认折叠可展开；每轮对话完成后消息下方提供复制/点赞/点踩并展示 token 与耗时；聊天区右上角提供会话搜索与工作空间文件入口；聊天区正上方展示数字人名称、挂载的 MCP 服务及其连接状态；支持切换/查看数字人并在下一轮生效；左侧历史栏支持查看历史记录与新建会话。"

**修订记录（2026-09-10）**：工具调用仅展示工具名、不输出调用结果且调用后消失；思考模式默认折叠思考输出；快速模式即未开启思考的模式；会话进行中禁止连续发送消息（发送按钮置灰）；上传失败提示原因并提醒重试；MCP 失败仅显示失败状态；会话进行中禁止切换数字人（按钮置灰）；历史会话默认 10 条并提供"更多"查看最近 100 次；外部地址直接跳转、tmp 临时空间地址必须在右侧展示；会话搜索黄色高亮且逐次跳转（类似 Word）；本轮回复失败或超时在聊天区正常显示错误信息；新增：输入"@"引用空间文件（展示空间文件夹、可选择文件、以 @文件名 形式插入且实际指向文件地址）。

**后端口径核对（2026-09-10）**：已对照后端源码逐接口复核，修正 4 处口径 —— ① 空间目录白名单为 **9 个**；② 左侧历史列表 10/100 条为**前端切片**（接口不支持分页参数）；③ 会话上限为**会话总数 3 个**（非并发数）；④ "会话进行中禁止切换数字人"为**前端体验约束**（后端未校验）。差异明细见 `contracts/backend-api.md` §7。

**修订记录（2026-09-10，契约对齐）**：依据后端 `specs/002-agent-chat-ui/contracts/`（`http-api.md`、`sse-events.md`）与 `docs/api.md` 完成对齐。主要变化：① 空间目录白名单**与后端同口径**，共 9 个（生产计划、产线信息、切换时间、求解时间、产线电价、目标优先级、使用规则、shared、tmp），上传入口、@ 引用与工作空间查看共用同一白名单；② 思考内容与工具调用信息**不落历史**，仅本轮流式期间可见；③ @ 引用以 `{dir, filename}` 结构化提交（≤10 个），非任意地址；④ 消息状态为 `completed|failed`，用量为 `{input_tokens, output_tokens}`；⑤ 数字人须先 select，切换为**覆盖式**（**2026-09-10 修订**：无需先 exit），会话进行中禁止切换（前端置灰，非后端兜底）；⑥ 新增"中断本轮"入口；⑦ 模型与思考为**请求级**参数；⑧ 补充上传/预览/创建会话的错误码与限制；⑨ 补充 SSE 断连语义。

**修订记录（2026-09-11，文件空间单区域双视图）**：右侧 1/3 收敛为**一个**工作空间面板，内部在"文件空间列表"与"文件内容"之间互换（不再有居中弹窗，也不并存两块区域）；文件空间按 9 个固定目录分组，默认**全部收起**、可折叠，折叠状态在本次会话内保持；新增文件删除能力（`shared` 为共享只读目录，后端 403 `FILE_READONLY`）。同步修订 FR-001、FR-002、FR-031、FR-046，新增 FR-053 ~ FR-055。

**修订记录（2026-09-10，目录口径确认）**：空间目录数量按后端白名单口径统一为 **9 个**（7 业务 + shared + tmp），"加号上传入口"、"@ 文件选择"、"工作空间文件"三处展示的目录集合完全一致；原需求中的"8 个空间文件夹"表述以本口径为准。

**修订记录（2026-09-10，一致性修订）**：关闭 3 项未决边界问题（工具调用的进行/结束状态呈现、刷新后"内容丢失"误解的规避、外链跳转被拦截时的降级）；FR-001 明确右侧预览区宽度容差、FR-002 去除与 FR-045/046 的重复表述、FR-042 定义"系统繁忙"、FR-044 明确标题由后端生成而前端仅负责展示、FR-049 明确错误信息在本轮消息位置内联展示；SC-003 补充可测量的验收方法。

**修订记录（2026-09-10，会话上限口径修正）**：`POST /api/threads` **取消会话总数上限**——原实现按"该数字人会话总数 ≥ 3"返回 409 `THREAD_BUSY_LIMIT`，现改为**只限并发**（同一用户同时进行中的会话 ≤ 3，按 **userId** 跨数字人累计，由发消息接口判定）。同步修订 US5 场景 6、FR-042、补充说明与后端契约对齐表；`THREAD_BUSY_LIMIT` 不再"同码不同义"。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 发起并完成一轮对话（优先级：P1）

用户打开页面时，对话入口位于页面中央，尚未开始对话。用户在入口中输入问题并发送后，页面展开
聊天区域，对话入口下移到聊天区底部，同时聊天区出现"思考中"的动态提示。在回复生成过程中，若发生
工具调用，仅展示工具名称、不展示工具调用的入参与结果内容，且调用结束后该展示消失；本轮未完成前
发送按钮置灰，用户不能连续发送消息，但可通过"中断本轮"结束生成。当回复完成时，回复内容展示在
聊天区；若开启思考模式，思考输出内容默认折叠、用户可点击展开查看；快速模式即未开启思考的模式，
不展示思考内容。

**优先级理由**：这是产品的核心价值路径，没有它其余功能都无意义；单独实现即可交付最小可用产品。

**独立测试**：进入页面 → 在居中入口发送一条消息 → 验证聊天区展开且入口下移 → 验证出现"思考中"提示
→ 验证发送按钮置灰 → 回复完成后验证思考内容默认折叠且可展开。

**验收场景**：

1. **给定** 用户首次进入页面且无进行中的会话，**当** 页面加载完成，**则** 对话入口居中显示且聊天区未展开。
2. **给定** 对话入口居中显示，**当** 用户输入内容并发送，**则** 聊天区展开且对话入口移动到聊天区下方。
3. **给定** 消息已发送且回复未返回，**当** 等待回复期间，**则** 聊天区展示持续动态旋转的"思考中"提示。
4. **给定** 回复生成过程中发生工具调用，**当** 收到工具调用开始事件，**则** 仅展示工具名称（不展示入参与结果内容）；收到配对的工具调用结束事件后，该展示消失。
5. **给定** 本轮回复尚未完成，**当** 用户查看发送按钮，**则** 发送按钮置灰不可用，用户无法在同一会话中连续发送消息。
6. **给定** 本轮回复正在生成，**当** 用户点击"中断本轮"，**则** 本轮生成被中断，本轮不产生落盘消息，也不展示操作按钮与用量数据。
7. **给定** 开启思考模式且回复已完成，**当** 回复展示时，**则** 思考输出内容默认折叠，用户点击后可展开查看，再次点击可收起。
8. **给定** 处于快速模式（未开启思考），**当** 回复完成，**则** 不展示思考内容。
9. **给定** 本轮对话已结束并落盘，**当** 用户重新加载该会话历史，**则** 历史消息中不包含思考内容与工具调用信息。

### 用户故事 2 - 消息级操作与用量反馈（优先级：P1）

一轮对话完成后，用户可在该条消息下方看到复制、点赞、点踩三个操作，以及本条消息消耗的
输入/输出 token 数与执行时间（秒）。用户点击复制可复制消息内容，点击点赞或点踩可表达反馈并看到选中状态；
重复点击同一反馈即取消。

**优先级理由**：用量透明度与反馈操作是用户评估结果、复用内容的关键；与核心对话共同构成最小可用产品。

**独立测试**：完成一轮对话 → 验证消息下方出现复制/点赞/点踩与 token、耗时 → 分别点击各按钮验证行为与状态。

**验收场景**：

1. **给定** 一轮对话已完成并落盘，**当** 用户查看该条消息，**则** 消息下方展示复制、点赞、点踩按钮以及输入/输出 token 数与执行时间（秒）。
2. **给定** 消息下方展示复制按钮，**当** 用户点击复制，**则** 消息内容被复制且用户获得成功反馈。
3. **给定** 消息下方展示点赞与点踩，**当** 用户点击其一，**则** 该按钮进入选中状态，另一个为未选中。
4. **给定** 用户已对某条消息点赞，**当** 用户再次点击点赞，**则** 反馈被取消（回到未选中状态）。
5. **给定** 回复仍在生成中，**当** 用户查看该条消息，**则** 不展示操作按钮与用量数据（待本轮完成后展示）。
6. **给定** 本轮被中断或未落盘，**当** 用户查看该轮消息，**则** 不展示点赞/点踩操作（无可关联的消息标识）。

### 用户故事 3 - 输入区工具选项（优先级：P2）

用户可在对话入口下方的功能选项中：点击最左侧的加号选择文档上传入口（与后端目录白名单同口径的 9 个空间目录），
点击最右侧的按钮在"思考"与"快速"之间切换（快速模式即未开启思考的模式），点击右二的按钮选择不同的 LLM 模型。
若文件上传失败，系统提示失败原因并提醒用户重试。

**优先级理由**：这些选项决定"怎么问"与"用哪个模型"，显著影响结果质量，但可在核心对话之后交付。

**独立测试**：打开输入区 → 点击加号验证出现全部上传入口 → 上传失败验证提示与重试 → 切换思考/快速并验证状态 → 选择模型并验证当前模型展示。

**验收场景**：

1. **给定** 对话入口已展示，**当** 用户查看入口下方，**则** 最左侧为加号按钮、最右侧为思考开关、右二为 LLM 模型按钮。
2. **给定** 用户点击加号，**当** 上传入口展开，**则** 展示全部 9 个空间目录入口（生产计划、产线信息、切换时间、求解时间、产线电价、目标优先级、使用规则、shared、tmp（临时空间）），与后端目录白名单一致。
3. **给定** 上传入口已展开，**当** 用户选择一个入口并选择文件，**则** 文件被上传并展示上传状态，可同时选择多个文件。
4. **给定** 用户选择的文件扩展名不在 `.csv .xlsx .txt .json .pdf` 之内或超过 50MB，**当** 上传执行，**则** 系统展示失败原因并提醒用户重试。
5. **给定** 思考开关处于默认状态，**当** 用户点击切换，**则** 在"思考"与"快速"之间切换，且快速模式为未开启思考的模式，当前模式清晰可见。
6. **给定** 用户点击 LLM 模型按钮，**当** 模型列表展开，**则** 展示可用模型并标识默认模型；选择后按钮显示新模型。
7. **给定** 用户选择的模型不可用，**当** 消息发送，**则** 系统提示模型不可用并保留用户输入。

### 用户故事 4 - 输入 @ 引用空间文件（优先级：P2）

用户上传文件后，在对话输入框中输入"@"时，展示空间文件夹（与后端目录白名单一致）；
用户可从每个文件夹中选择文件，选中后输入框中以"@文件名"的形式插入该文件引用，
实际引用的是该文件在对应目录下的定位（目录 + 文件名）。

**优先级理由**：让用户能精准引用已上传的空间文件作为对话上下文，显著提升提问精度；依赖上传能力，可在核心对话之后交付。

**独立测试**：上传文件 → 在输入框输入"@" → 验证展示空间文件夹 → 展开某个文件夹并选择文件 → 验证输入框插入"@文件名"且发送时携带真实文件定位。

**验收场景**：

1. **给定** 用户已上传文件，**当** 用户在输入框中输入"@"，**则** 展示全部 9 个空间文件夹（与后端目录白名单一致：生产计划、产线信息、切换时间、求解时间、产线电价、目标优先级、使用规则、shared、tmp）。
2. **给定** 已展示空间文件夹，**当** 用户展开某个文件夹，**则** 展示该文件夹内的文件列表。
3. **给定** 用户在某文件夹中选中一个文件，**当** 选中确认，**则** 输入框中以"@文件名"形式插入该文件引用。
4. **给定** 输入框中已插入"@文件名"，**当** 用户发送消息，**则** 以"目录 + 文件名"的结构化形式提交该引用，而非仅展示文本。
5. **给定** 用户在一条消息中引用了超过 10 个文件，**当** 用户继续选择文件，**则** 系统阻止继续添加并提示引用数量上限。
6. **给定** 被引用的文件已被删除或不存在，**当** 用户发送消息，**则** 系统提示引用文件不存在，且消息不发送。
7. **给定** 某个空间文件夹为空，**当** 用户展开该文件夹，**则** 展示空状态提示。
8. **给定** 文件选择面板已展开，**当** 用户删除输入框中的"@"触发符，**则** 文件选择面板收起。

### 用户故事 5 - 历史会话与新建会话（优先级：P2）

左侧历史记录栏默认展示最近 10 条历史会话，用户点击某条可查看该会话内容；通过"更多"选项可查看
最近 100 次会话；历史栏上方提供新建会话入口，点击后弹出新的会话聊天。

**优先级理由**：会话管理是高频操作，但可在核心对话与工具选项之后交付。

**独立测试**：打开页面 → 验证默认展示 10 条 → 点击历史项验证切换 → 点击"更多"验证可查看 100 次 → 点击新建验证弹出新会话。

**验收场景**：

1. **给定** 用户存在历史会话，**当** 用户查看左侧栏，**则** 默认展示最近 10 条历史会话（按最后更新时间倒序），且每项可点击。
2. **给定** 历史列表已展示，**当** 用户点击某条历史记录，**则** 中间聊天区加载该会话内容，并展示其消息（按时间正序）。
3. **给定** 历史列表已展示，**当** 用户点击"更多"选项，**则** 可选择查看最近 100 次会话。
4. **给定** 历史列表已展示，**当** 用户点击列表上方的新建会话入口，**则** 弹出新的空白会话聊天。
5. **给定** 用户未选择数字人，**当** 用户点击新建会话，**则** 系统提示需先选择数字人。
6. **给定** 该用户已有 3 个回复进行中（可分布在同一个或不同数字人上），**当** 用户对第 4 个会话发送消息，**则** 系统提示"系统繁忙"（`THREAD_BUSY_LIMIT` 是并发上限，按 userId 跨数字人累计）；新建会话本身不受会话总数限制。
7. **给定** 用户无任何历史会话，**当** 用户查看左侧栏，**则** 展示空状态提示且新建入口仍可用。
8. **给定** 会话已有用户消息，**当** 用户在历史列表中查看该会话，**则** 展示的标题取自首条用户消息（截取前 20 字）。

### 用户故事 6 - 数字人信息与切换（优先级：P2）

聊天区正上方展示当前数字人的名称及其挂载的 MCP 服务，每个 MCP 服务显示连接状态
（红色表示失败、绿色表示正常连接）。聊天区右上角的数字人按钮可查看数字人明细或切换数字人；
明细区默认为当前数字人，点击列表中的其他数字人名称可**只读预览**其配置（不切换、不受会话进行中限制），
预览态可直接切换或点回当前数字人退出预览；
当存在进行中的会话时，切换按钮置灰不可用，只有当前无进行中的会话时才能切换；切换并确认新的
数字人后，新配置在下一轮对话时重新初始化生效。

**优先级理由**：数字人与 MCP 状态直接影响可信度与可观测性，但依赖数字人/服务能力，可在核心对话后交付。

**独立测试**：打开聊天区 → 验证数字人名称与 MCP 状态展示 → 会话进行中验证切换按钮置灰 → 无进行中会话时切换并验证下一轮生效。

**验收场景**：

1. **给定** 聊天区已展开，**当** 用户查看聊天区正上方，**则** 展示当前数字人名称。
2. **给定** 当前未选择数字人，**当** 用户查看聊天区正上方，**则** 提示需要选择数字人；此时 MCP 服务列表为空。
3. **给定** 数字人已挂载 MCP 服务，**当** 用户查看服务列表，**则** 每个服务以颜色标识状态：红色=失败，绿色=正常连接。
4. **给定** 数字人实例尚未创建（从未发消息），**当** 用户查看 MCP 服务状态，**则** 所有服务显示为失败状态。
5. **给定** 用户点击聊天区右上角的数字人按钮，**当** 面板展开，**则** 可查看数字人明细（描述、技能、已启用工具、挂载的 MCP 服务），并可点击列表中其他数字人的名称**只读预览**其明细（**不触发**切换请求）。
6. **给定** 当前存在进行中的会话，**当** 用户查看数字人切换入口，**则** 切换按钮置灰不可用，用户无法切换数字人。
7. **给定** 当前无进行中的会话且已选中另一数字人，**当** 用户切换并确认新的数字人，**则** 系统**直接覆盖式选定**新数字人（无需先退出），并在下一轮对话时生效。
8. **给定** 某个 MCP 服务处于失败状态，**当** 用户查看状态，**则** 该服务仅以失败状态（红色）显示，不做额外阻断或弹窗提示。

### 用户故事 7 - 内容跳转与右侧预览（优先级：P3）

当聊天区中出现可跳转的内容时：若为外部地址，则直接跳转到外部链接；若为空间目录（含 tmp 临时空间）
中的文件，则在右侧约 1/3 宽的预览区中内联展示该文件内容。

**优先级理由**：提升信息查阅效率，但属于增强体验，可在主流程稳定后交付。

**独立测试**：点击外部地址验证直接跳转 → 点击空间目录文件验证右侧 1/3 区域内联渲染 → 验证无跳转内容时的占位状态。

**验收场景**：

1. **给定** 聊天区中存在外部地址，**当** 用户点击该地址，**则** 系统直接跳转到外部链接（不在右侧预览区打开）。
2. **给定** 聊天区中存在空间目录（含 tmp）中的文件引用，**当** 用户点击该文件，**则** 右侧约 1/3 宽的预览区以**内联**方式展示该文件内容。
3. **给定** 右侧预览区正在展示文件，**当** 用户点击另一处文件，**则** 预览区更新为新内容。
4. **给定** 尚无任何跳转内容，**当** 用户查看页面，**则** 右侧区域展示占位或收起状态，不影响聊天区宽度使用。
5. **给定** 用户点击的文件为 `.xlsx`，**当** 预览执行，**则** 系统回退为下载该文件。
6. **给定** 用户点击的文件已不存在（如 tmp 已被清理），**当** 预览执行，**则** 预览区展示"文件不存在"提示。
7. **给定** 用户点击的文件超过预览大小上限，**当** 预览执行，**则** 预览区提示文件过大并引导下载完整文件。

### 用户故事 8 - 会话内容搜索与工作空间文件（优先级：P3）

聊天区右上角提供搜索按钮，可搜索当前会话内容；匹配结果以黄色高亮显示，每点击一次搜索就跳转到
下一个匹配（与 Word 查找功能一致）。同一区域提供工作空间文件按钮，可查看用户自己的工作空间文件。

**优先级理由**：面向长会话与文件管理的效率增强功能，可在核心流程之后交付。

**独立测试**：打开聊天区 → 输入关键词验证黄色高亮与首次定位 → 再次点击搜索验证跳转下一个匹配 → 点击工作空间文件验证文件列表。

**验收场景**：

1. **给定** 会话中存在多条消息，**当** 用户点击搜索按钮并输入关键词，**则** 匹配结果以黄色高亮显示并定位到首个匹配项。
2. **给定** 搜索已有匹配结果，**当** 用户再次点击搜索，**则** 跳转到下一个匹配项，并在到达末尾后循环回到首个匹配。
3. **给定** 用户已输入关键词但无匹配，**当** 搜索执行，**则** 展示无结果提示。
4. **给定** 用户点击工作空间文件按钮，**当** 面板展开，**则** 按目录展示当前用户的工作空间文件（覆盖全部空间目录，空目录展示为空）。

### 边界情况

- 当本轮回复未完成时，用户尝试再次发送消息，系统如何响应（发送按钮置灰；后端以"该对话已有进行中的回复"冲突兜底）？
- 工具调用耗时较长或失败时：仅展示的工具名条目持续呈现"进行中"状态；收到配对的结束事件后该条目立即消失；若本轮以失败或中断结束而仍有未配对的条目，则随本轮结束一并清除。
- 当思考内容或回复内容极长时，折叠与展开如何保持可读与可滚动？
- 用户刷新或重新进入会话时，思考内容与工具调用信息不再可见（不落历史）：前端 MUST NOT 以占位符、"已删除"标记或数量缺口等任何形式暗示内容丢失，历史仅呈现消息正文。
- 当上传过程中网络中断、文件超限（>50MB）或扩展名不符时，如何提示失败原因并提醒重试？
- 当上传目标目录不在白名单内时，如何提示？
- 当 MCP 服务在对话进行中由正常变为失败时，如何仅更新为失败状态？
- 当数字人实例首次建连尚未完成时，MCP 服务状态如何呈现（暂按失败，建连完成后更新）？
- 当会话进行中用户尝试切换数字人时，置灰的切换按钮如何提示原因？
- 当用户已选中一个数字人、又尝试切换另一个时，如何提示"切换将在下一轮对话生效"？
- 当会话历史少于 10 条、恰好 10 条或超过 100 条时，"更多"入口如何展示？
- 当流式连接意外断开时，如何提示并让用户重新获取本轮结果（本轮仍会继续执行并落盘）？
- 外部地址跳转被浏览器拦截（如弹窗被阻止）时：系统 MUST 降级为在当前标签页直接跳转，MUST NOT 静默失败；目标站点要求授权的情形由目标站点自行处理，前端不做额外拦截。
- 当空间目录中的文件已被删除或不可渲染时，右侧预览区如何提示？
- 当会话搜索关键词命中大量结果时，黄色高亮与逐次跳转如何保证可定位？
- 当本轮回复失败或超时时，聊天区如何正常显示错误信息？
- 当用户在"@"后继续输入关键词时，如何筛选各空间文件夹中的文件？
- 当一条消息中引用多个空间文件时，如何展示与解析？
- 当 9 个空间目录均为空时，如何提示？
- 当后端目录白名单发生增减（新增或移除目录）时，前端三处目录集合如何保持同步？

## 需求 *(必填)*

### 功能需求

**整体布局**

- **FR-001**: 系统 MUST 提供三栏布局：左侧为历史对话记录、中间为聊天区、右侧为**工作空间面板**（文件空间列表与文件内容预览在同一面板内互换，MUST NOT 拆成两块并存的区域）；右侧面板宽度 MUST 约为页面宽度的 1/3（容差 ±5%）。
- **FR-002**: 右侧工作空间面板收起时 MUST NOT 压缩聊天区的可用宽度；展开后 MUST 占据约 1/3 宽度。跳转与内联预览的具体行为见 FR-045 / FR-046。

**初始与对话展开**

- **FR-003**: 用户首次进入且无进行中会话时，对话入口 MUST 居中显示，聊天区 MUST 不展开。
- **FR-004**: 用户发起对话后，聊天区 MUST 展开，且对话入口 MUST 移动到聊天区下方。
- **FR-005**: 在回复生成过程中，工具调用 MUST 仅展示工具名称与进行状态，MUST NOT 展示工具调用的入参、过程输出或结果内容；工具调用结束后该展示 MUST 消失。
- **FR-006**: 用户 MUST NOT 在同一会话中连续发送消息；当本轮回复未完成时，发送按钮 MUST 置灰且不可用。
- **FR-007**: 本轮回复生成过程中，系统 MUST 提供"中断本轮"入口；中断后本轮 MUST NOT 产生落盘消息，且 MUST NOT 展示操作按钮与用量数据。

**输入区工具选项**

- **FR-008**: 对话入口下方 MUST 展示功能选项，最左侧为加号（文档上传）、最右侧为思考开关、右二为 LLM 模型选择。
- **FR-009**: 点击加号后 MUST 展示全部 9 个空间目录的上传入口（生产计划、产线信息、切换时间、求解时间、产线电价、目标优先级、使用规则、shared、tmp），目录集合 MUST 与后端目录白名单完全一致。
- **FR-010**: 每个上传入口 MUST 支持选择文件上传，MUST 支持一次选择多个文件并展示上传状态；仅接受 `.csv .xlsx .txt .json .pdf` 扩展名且单文件不超过 50MB。
- **FR-011**: 文件上传失败时，系统 MUST 提示失败原因（如文件过大、格式不支持、目录不可写、目录不在白名单），并 MUST 提醒用户重试。
- **FR-012**: 思考开关 MUST 可在"思考"与"快速"两种模式之间切换；快速模式 MUST 为未开启思考的模式；系统 MUST 明确展示当前模式。
- **FR-013**: LLM 模型按钮 MUST 支持选择不同模型，并 MUST 展示当前选中模型与默认模型标识；模型为请求级参数，MUST 随每条消息提交，缺省时使用默认模型。

**文件引用（@ 提及）**

- **FR-014**: 用户上传文件后，在输入框中输入"@"时，系统 MUST 展示全部 9 个空间目录（与"加号上传入口"及"工作空间文件"展示的目录集合完全一致，同后端白名单口径）。
- **FR-015**: 用户 MUST 能从任一空间目录中选择文件，选中后输入框 MUST 以"@文件名"形式插入该文件引用。
- **FR-016**: "@文件名"引用 MUST 以"目录 + 文件名"的结构化形式随消息提交，MUST NOT 仅作为纯文本处理。
- **FR-017**: 单条消息的引用数量 MUST NOT 超过 10 个；超出时系统 MUST 阻止继续添加并提示上限。
- **FR-018**: 当被引用的文件不存在时，系统 MUST 提示引用文件不存在，且 MUST NOT 发送该消息。
- **FR-019**: 当某个空间目录为空时，系统 MUST 展示空状态提示。

**思考与等待反馈**

- **FR-020**: 在等待回复期间，聊天区 MUST 展示动态旋转的"思考中"装饰以提示正在输出。
- **FR-021**: 在开启思考的模式下，思考输出内容 MUST 默认折叠，用户 MUST 能点击展开与收起。
- **FR-022**: 在快速模式（未开启思考）下，系统 MUST NOT 展示思考内容。
- **FR-023**: 思考内容与工具调用信息 MUST NOT 持久化到会话历史；用户重新加载会话时，系统 MUST NOT 期望其可恢复展示。

**消息级操作与用量**

- **FR-024**: 一轮对话完成并落盘后，该条消息下方 MUST 提供复制、点赞、点踩三个操作。
- **FR-025**: 一轮对话完成并落盘后，该条消息 MUST 展示本条消息消耗的输入/输出 token 数与执行时间（秒）。
- **FR-026**: 复制操作 MUST 复制该条消息内容，并向用户提供成功反馈。
- **FR-027**: 点赞与点踩 MUST 互斥且可选中；重复点击同一反馈 MUST 取消该反馈。
- **FR-028**: 在回复生成过程中、本轮被中断或本轮未落盘时，系统 MUST NOT 展示该轮的操作按钮与用量数据。

**搜索与工作空间**

- **FR-029**: 聊天区右上角 MUST 提供搜索按钮，可搜索当前会话内容；匹配结果 MUST 以黄色高亮显示。
- **FR-030**: 每点击一次搜索 MUST 跳转到下一个匹配项（与 Word 查找行为一致），并 MUST 支持到达末尾后循环定位。
- **FR-031**: 聊天区右上角 MUST 提供工作空间文件按钮；点击后 MUST 展开右侧工作空间面板并停在**文件空间列表态**，按目录展示当前用户的工作空间文件（覆盖全部 9 个空间目录）；分组 MUST 可折叠展开且**默认全部收起**，折叠状态 MUST 在本次会话内保持；再次点击该按钮 MUST 收起面板。空目录展开后 MUST 展示空状态提示（FR-019）。

**数字人与 MCP**

- **FR-032**: 聊天区正上方 MUST 展示当前数字人名称；未选择数字人时 MUST 提示需要选择。
- **FR-033**: 系统 MUST 展示当前数字人挂载的 MCP 服务列表，并以颜色标识状态（红色=失败，绿色=正常连接，灰色=未连接）；未选择数字人时列表为空。
- **FR-034**: 数字人实例尚未创建或其 MCP 服务尚未产生建连结果时，状态 MUST 呈现为"未连接"（灰色）并在建连结果产生后更新，MUST NOT 呈现为失败。（**2026-09-11 修订**：原为"MUST 呈现为失败"，会导致切换数字人后未发起对话时被误读为断线故障）
- **FR-035**: 聊天区右上角的数字人按钮 MUST 支持查看数字人明细（描述、技能、已启用工具、挂载的 MCP 服务）与切换数字人；对**未选中**的数字人 MUST 支持**只读预览**其明细（标注"预览中"、不触发切换）；预览 MUST NOT 受"会话进行中"限制（仅**切换**受限，FR-036）。
- **FR-036**: 当用户存在进行中的会话时，数字人切换 MUST 置灰且不可用；仅当无进行中的会话时，用户 MUST 能切换数字人。
- **FR-037**: 切换数字人时，系统 MUST 以**单次覆盖式选中**完成切换（MUST NOT 要求用户先退出当前数字人）；确认切换后，新配置 MUST 在下一轮对话时生效。
- **FR-038**: 当 MCP 服务失败时，系统 MUST 仅以失败状态（红色）展示，MUST NOT 做额外阻断或弹窗提示。

**历史会话**

- **FR-039**: 左侧历史记录栏 MUST 默认展示最近 10 条历史会话（按最后更新时间倒序），且每项 MUST 可点击查看对应会话。
- **FR-040**: 历史记录栏 MUST 提供"更多"入口，用户可选择查看最近 100 次会话。
- **FR-041**: 历史记录栏上方 MUST 提供新建会话入口，点击后 MUST 弹出新的会话聊天。
- **FR-042**: 当新建会话失败时，系统 MUST 给出明确提示，覆盖以下情形：用户未选择数字人、数字人不存在或配置异常，以及后端返回 5xx 或网络异常（以下统称"系统繁忙"）。
- **FR-043**: 当无历史会话时，系统 MUST 展示空状态，且新建入口 MUST 保持可用。
- **FR-044**: 会话标题 MUST 由后端依据首条用户消息生成（截取前 20 字），前端 MUST 直接展示该标题；当后端返回的标题为空时，前端 MUST 展示占位标题"新会话"。

**跳转与预览**

- **FR-045**: 当跳转内容为外部地址时，系统 MUST 直接跳转到外部链接，MUST NOT 在右侧预览区打开。
- **FR-046**: 当跳转内容为空间目录中的文件时，系统 MUST 在右侧工作空间面板内由列表态**切换为内容态**并内联展示该文件内容（MUST NOT 另开弹窗、MUST NOT 与列表并存）；消息内的文件引用与面板内的文件点击 MUST 走同一入口；内容态 MUST 提供返回列表的入口，返回后面板保持展开。
- **FR-047**: 当预览文件为电子表格类（如 `.xlsx`）时，系统 MUST 回退为下载该文件。
- **FR-048**: 当预览文件不存在、超过预览大小上限或不可渲染时，右侧预览区 MUST 展示明确的错误提示（含引导下载）。

**健壮性与质量约束**

- **FR-049**: 本轮回复失败或超时时，聊天区 MUST 在该轮消息位置内联展示错误信息（含错误原因文案），MUST NOT 以无响应或静默方式结束本轮。
- **FR-050**: 当流式连接意外断开时，系统 MUST 提示用户，并 MUST 支持通过重新获取会话历史得到本轮最终结果（本轮在服务端继续执行并落盘）。
- **FR-051**: 所有交互控件（按钮、输入框、开关、列表项）MUST 支持键盘导航并遵循 WAI-ARIA 无障碍指南。
- **FR-052**: 所有交互反馈延迟 MUST NOT 超过 100ms；LLM/Agent 推理相关交互除外，但 MUST 提供加载或流式反馈状态。

**文件空间管理**

- **FR-053**: 文件空间列表的每个文件 MUST 提供"查看"与"下载"入口；对**非只读目录** MUST 额外提供"删除"入口。`shared` 为共享目录，其内容 MUST 为只读——前端 MUST NOT 渲染删除入口，后端对删除该目录文件的请求 MUST 返回 403 `FILE_READONLY`。
- **FR-054**: 删除文件 MUST 经**二次确认**后才发起请求；成功后该条目 MUST 从列表移除并向用户提示成功；失败时 MUST 提示失败原因且 MUST NOT 改变列表。
- **FR-055**: 删除操作的目标文件若正处于内容态展示中，删除成功后面板 MUST 自动退回列表态；工作空间面板收起后再展开时 MUST 默认回到列表态。

### 关键实体

- **会话（Conversation）**：一次完整的对话记录，包含会话标识、**最近使用的数字人**（会话不绑定数字人，可在会话内切换，**2026-09-10 修订**）、标题（取首条用户消息前 20 字）、创建时间、最后更新时间、消息集合与进行中标志；可被创建、查看与切换。
- **消息（Message）**：会话中的单条内容，包含消息标识、角色（用户/数字人）、正文、时间戳、状态（完成/失败）、用量（输入/输出 token）、执行耗时（秒）、**所属数字人**（该轮回答者，会话可跨数字人）、文件引用（目录 + 文件名，仅用户消息）、反馈（点赞/点踩/无）与错误信息（失败时）。
  - 说明：思考内容与工具调用信息仅存在于本轮流式过程中，**不随消息持久化**。
- **数字人（Digital Human）**：可被选定与切换的对话主体，包含名称、描述、技能、已启用工具与挂载的 MCP 服务集合；必须先选定才能创建会话；切换为**覆盖式**（无需先退出，**2026-09-10 修订**），会话不绑定数字人。
- **MCP 服务（MCP Service）**：数字人挂载的外部能力服务，包含名称、传输方式与连接状态（正常/失败）；失败时仅展示失败状态。
- **模型（Model）**：可选用的 LLM 模型，包含模型标识与是否为默认模型；为请求级参数。
- **空间目录（Space Directory）**：文件空间的目录集合，共 9 个 —— 生产计划、产线信息、切换时间、求解时间、产线电价、目标优先级、使用规则、shared、tmp；与后端白名单同口径，是上传入口、@ 引用与工作空间查看的共同目录集合。
- **上传文档（Uploaded Document）**：用户通过上传入口提交的文件，包含所属目录、文件名、大小、更新时间与上传状态（含失败原因）。
- **文件引用（File Reference）**：用户在输入框中通过"@"选择生成的文件引用，展示形式为"@文件名"，实际以"目录 + 文件名"结构化提交，单条消息上限 10 个。
- **工作空间（Workspace）**：按目录聚合的当前用户文件集合，覆盖全部空间目录。
- **预览内容（Preview Content）**：用户在聊天区触发跳转的内容，包含来源类型（外部地址 / 空间目录文件）与内容类型（文本、JSON、CSV、PDF、电子表格等）；外部地址直接跳转，空间目录文件在右侧内联预览。

## 假设

- **接口依据**：后端 `specs/002-agent-chat-ui/contracts/http-api.md`、`sse-events.md` 与 `docs/api.md` 为唯一接口依据；所有路径以 `/api` 为前缀，本期无认证，请求归属内置用户。
- 该页面面向单用户工作台，v1 不包含多租户、角色与权限体系。
- 支持现代桌面浏览器；移动端适配不在 v1 范围内。
- "workbuddy 风格"指现代三栏工作台式视觉风格，具体视觉规范在设计与计划阶段细化。
- 空间目录**与后端同口径**：白名单共 9 个目录 —— 7 个业务目录（生产计划、产线信息、切换时间、求解时间、产线电价、目标优先级、使用规则）+ 共享目录 `shared` + 临时空间 `tmp`；上传入口、@ 引用与工作空间查看三处共用同一白名单，展示的目录集合必须完全一致（原需求中"8 个空间文件夹"的表述以本口径为准）。
- 文件上传限制：扩展名 `.csv .xlsx .txt .json .pdf`，单文件 ≤50MB；落盘文件名由服务端追加时间戳。
- 文件预览限制：存在内联预览大小上限（默认 10MB），超限需引导下载；电子表格类回退为下载。
- 思考开关与 LLM 模型选择为**请求级**参数，随每条消息提交；前端保持输入区的当前选择作为默认值；快速模式即未开启思考（`thinking=false`）。
- 思考内容与工具调用信息不落历史，仅在本轮流式期间可见。
- 工具调用仅展示工具名称与状态，不展示入参、过程输出与结果内容，调用结束后展示消失。
- 数字人必须先选定才能创建会话；切换数字人为**覆盖式**（后端已移除 409 `AGENT_SWITCH_REQUIRED`，无需先退出），**会话不绑定数字人**，可在同一会话内切换，新数字人在下一轮对话生效。
- "会话进行中禁止切换数字人"为**前端体验约束**（入口置灰、不发请求）。经后端源码核对，`select` / `exit` **未校验**进行中会话，服务端无兜底拦截（后端 spec `FR-021` 的实现缺口，详见 `contracts/backend-api.md` §7 差异 3）。
- 会话数量**只限并发**：同一用户同时进行中的会话上限 3 个（**跨数字人累计**），超出时发消息返回 409 `THREAD_BUSY_LIMIT`；**新建会话不设总数上限**（原"会话总数 ≥ 3 即拒绝创建"的口径已废止）。
- 外部地址直接跳转到外部链接；空间目录中的文件在右侧预览区内联展示。
- 左侧历史会话默认展示最近 10 条，可通过"更多"查看最近 100 次会话。
- 流式连接断开后，本轮仍在服务端继续执行并完整落盘；前端通过重新获取会话历史得到最终结果。
- Agent 对话交互设计可参考 RICH 设计范式（Read、Interact、Confirm、Handoff）作为体验框架。
- 会话历史持久化由后端提供，前端负责展示与切换。

## 后端契约对齐 *(依赖)*

> 本节仅记录功能点与后端契约的对应关系，用于可追溯性；具体调用方式在计划阶段确定。

| 功能点 | 契约来源 | 关键约束 |
|---|---|---|
| 会话列表（10/100 条） | `GET /api/threads` | 按更新时间倒序；该接口**不支持 `limit`/`offset`**，10/100 条由**前端切片**；`title` 由后端回落为"首条用户消息前 20 字" |
| 会话详情（消息、用量、反馈） | `GET /api/threads/:id` | 消息按时间正序；支持 `limit`（默认 50/上限 200）与 `offset`（从最新往前数）；`running` 标志本轮是否进行中 |
| 新建会话 | `POST /api/threads` | 未选定数字人 / 已选中其他数字人 → 409 提示；配置损坏 → 404；**不限制会话总数** |
| 发送消息（流式） | `POST /api/threads/:id/messages` | 请求体含 `content / thinking / model / attachments`；进行中重复发送 / 未选数字人 / 会话与当前数字人不一致 / 并发超限 → 409 |
| 流式事件 | `sse-events.md` | `thinking`、`content`、`tool_call`、`tool_call_end`、`done`、`error` |
| 工具调用展示 | `tool_call` / `tool_call_end` | 仅含工具名与状态，按调用标识配对，结束后消失 |
| 思考内容 | `thinking` | 实时增量、**不落历史** |
| 用量与耗时 | `done` / `error` / 会话详情 | 输入/输出 token 与整轮耗时（秒）；后端精度不固定，前端统一格式化为 1 位小数 |
| 消息反馈 | `PUT /api/threads/:id/messages/:mid/feedback` | 点赞/点踩互斥；同值重复提交=取消；`message_id` 须用会话详情返回的 `id` |
| 中断本轮 | `POST /api/threads/:id/stop` | 本轮不落盘；已消耗 token 仍计入用量 |
| 模型列表 | `GET /api/models` | 含默认模型标识（正常配置下恰一项为 `true`） |
| 当前数字人 | `GET /api/agents/current` | 未选定返回 `agent_name: null` |
| 数字人明细 | `GET /api/agents/:name` | 描述、技能、已启用工具、MCP 服务（不含连接细节） |
| 选定/退出数字人 | `POST /api/agents/:name/select`、`POST /api/agents/current/exit` | **覆盖式选中**（切换无需先 exit，2026-09-10 修订；已选中他人 → 200 覆盖）；"进行中禁止切换"为**前端约束**，后端未校验 |
| MCP 状态 | `GET /api/agents/current/mcp` + SSE `GET /api/agents/current/mcp/events` | 状态三态 connected/failed/unknown；实例未创建或建连进行中为 unknown（2026-09-11 修订）；状态更新经 SSE 推送，断线即时反映（2026-09-12 修订） |
| 文件上传 | `POST /api/files/upload` | 目录白名单（9 个：7 业务 + shared + tmp）、扩展名与 50MB 限制；**单文件接口，多选须逐文件请求** |
| 文件引用 | 发送消息请求体 `attachments` | 目录 + 文件名；上限 10；目录非白名单 → 403；文件不存在 → 400 拒绝发送 |
| 文件内联预览 | `GET /api/files/preview` | 内联展示、按扩展名映射类型、超预览上限（10MB）提示下载；`.xlsx` 回退下载 |
| 工作空间 | `GET /api/files/workspace` | 覆盖全部 9 个空间目录，空目录为空数组 |
